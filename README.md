# PilahSampah - Web Interaktif Edukasi & Simulasi Pilah Sampah

![PilahSampah Banner](Assets/Animasi%20Rotasi%20Bumi.mp4)

## A. Judul & Deskripsi
* **Nama Produk Digital:** PilahSampah (EcoLife Experience)
* **Latar Belakang Masalah:**  
  Rendahnya kesadaran dan pemahaman masyarakat, khususnya generasi muda, mengenai kategori pemilahan sampah di tingkat rumah tangga sering kali menyebabkan penumpukan limbah tak terpilah di TPA. Metode edukasi konvensional cenderung membosankan dan kurang interaktif.
* **Target Pengguna:**  
  Siswa, mahasiswa, serta masyarakat umum yang ingin mempelajari tata cara pemilahan sampah secara menyenangkan, visual, dan interaktif.

---

## B. Teknologi yang Digunakan
* **Bahasa Pemrograman:** HTML5, CSS3, JavaScript (ES6+)
* **Pustaka & Modul:** 
  * [Font Awesome v6.4.0](https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css) (Ikonografi UI)
  * Google Fonts - Poppins (Tipografi)
  * Web Audio API (Efek suara interaktif tanpa dependensi eksternal)
* **Platform Publikasi:** GitHub Pages

---

## C. Pemanfaatan AI (AI Usage Disclosure)
* **Alat AI yang Digunakan:** Gemini (Google AI)
* **Contoh Perintah (Prompt) Utama:**
  1. *"Ingin membuat website interaktif bertema Pilah Sampah dengan desain modern bergaya paper-cut layer / EcoLife dan animasi rotasi bumi di halaman awal."*
  2. *"Meminta struktur file terpisah index.html, style.css, dan script.js beserta simulasi game pilah sampah dan kalkulator dampak."*
  3. *"Buka logikanya agar tempat sampah tidak memiliki teks petunjuk jawaban dan ubah halaman awal menggunakan aset video looping lokal."*
* **Penyesuaian & Perbaikan Mandiri:**
  * **Penyederhanaan UI Game:** Menghapus petunjuk teks pada kartu tempat sampah dari saran awal AI untuk meningkatkan aspek tantangan dan edukasi permainan.
  * **Optimasi Performa:** Mengganti render 3D JavaScript/Three.js yang berat dengan pemutaran video MP4 lokal (`Assets/Animasi Rotasi Bumi.mp4`) berfitur `autoplay loop muted` agar responsif di seluruh perangkat.
  * **Penyesuaian Branding:** Mengonsistenkan penamaan merek menjadi **PilahSampah**.
